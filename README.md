# 📈 ScoreScanner — Painel Interativo de Análise e Escaneamento de Mercado

> **Desenvolvido por:** Marco Antônio Rosa  
> **Tecnologias:** HTML5 | JavaScript (ES6+) | CSS3 (Dark Theme & Glassmorphism) | Financial Analytics  
> **Versão:** 31.0 (Web Standalone)  

---

## 📌 Visão Geral

O **ScoreScanner** é uma ferramenta web interativa avançada para análise técnica, escaneamento de ativos financeiros e avaliação de score de oportunidade de mercado em tempo real.

O projeto conta com interface em modo escuro (Dark Theme), cálculo dinâmico de indicadores, regras de filtros configuráveis e acompanhamento de stops/metas.

## ⚙️ Como Executar

### Opção 1: Execução Direta
Basta dar dois cliques no arquivo `index.html` para abrir o painel em qualquer navegador (Chrome, Edge, Firefox, Brave).

### Opção 2: Servidor Local
```bash
# Com Python
python -m http.server 8000
```
Acesse no navegador: `http://localhost:8000`
